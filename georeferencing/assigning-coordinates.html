10.2 Ground control points

On the previous page you learned how to load an image into the Georeferencer. The next step is to position it unambiguously in geographical space by assigning coordinates to it.

From a technical point of view, your scanned map is a raster image that can consist of thousands or even millions of pixels or raster cells. Of course, you are not expected to enter the geographic coordinates of each of these cells by hand. Instead, you provide the coordinates of a limited number of points on the image, called ground control points (GCPs), or simply control points. Based on these points, QGIS establishes a mathematical transformation to calculate the geographic coordinates of all other pixels automatically.

The accuracy of this calculation depends on how well the control points represent the actual geographical locations they refer to, and of course on the geometric quality of the map itself. Especially historical maps are often imperfect in this regard, as you will see on the next page.

Creating GCPs

In the QGIS georeferencer, you add a control point by first selecting the button (Add GCP Point) and then clicking on the image where you want to place it. A pop-up window (Enter Map Coordinates) opens in which you can enter the coordinates of this point. In this window you also choose the coordinate reference system (CRS) in which you enter these coordinates. Although this procedure might not sound too hard, it is easier said than done: unless the coordinates of the control point are stated on your image (for example if a grid is shown), you will rarely know them.

Homologous points

Fortunately, there is a practical alternative, which is also the most widely used method: you indicate the corresponding point in the main map canvas of your QGIS project. Such corresponding points on the image and on the map are called homologous points.

Creating homologous points

  1. Click the point on the map in the Georeferencer with (Add GCP Point). The pop-up window Enter Map Coordinates opens.
  2. Click From Map Canvas at the bottom of the pop-up window. You are taken to the main QGIS window (if Automatically hide georeferencer window is ticked, the Georeferencer is hidden while you do this).
  3. Click the corresponding position in the main map canvas. Its coordinates are automatically assigned to the control point on the image. They are in the CRS of your QGIS project (the project CRS), and the CRS in the pop-up window is set to it automatically.

With the buttons (Move GCP Point) and (Delete GCP Point) you can move or delete a control point afterwards.

Useful tools

The buttons (Link Georeferencer to QGIS) and (Link QGIS to Georeferencer) are a great help while defining homologous points. They link the map canvases of the Georeferencer and the main QGIS window based on the points you have already set: if you zoom in or pan in one window, the other window follows and shows the same area. That way you can quickly find the corresponding place for your next control point. Be aware that these buttons don’t work if you don’t have enough GCPs, and are even greyed out if you haven’t chosen a transformation type in the Transformation Settings yet (see Running the georeferencing).

Saving your GCPs

You can save your control points as a.points file with (Save GCP Points as) and load them again with (Load GCP Points). That way you can continue working on them later. A points file stores the relationship between the pixels of the original image and the coordinates you assigned to them. It can therefore only be used with that original image: you cannot use it for another scan of the same map, or even for a cropped version of it.

If your points file has the same name as the original image file and is saved in the same folder, QGIS automatically loads the saved GCPs into the georeferencer when you open the image file.

GCPs in practice

When you choose homologous points, always keep the following in mind:

  • Make sure that the two homologous points really are the same. When you georeference historical maps, this is not always obvious: over time, buildings are sometimes replaced by other buildings with different dimensions, bridges are moved, open spaces become smaller…

  • Be as precise as possible. Corners of buildings and of (water)ways are usually better control points than random points in the middle of a map element. For the same reason, for small-scale maps, villages are usually more useful than large cities, where it is harder to point to exactly the same location.

  • Make sure that the base map you use to indicate homologous points is itself reliable and correctly georeferenced. In QGIS you can for example use the OpenStreetMap layer (see XYZ Tiles in Services). This present-day map is detailed, covers almost the whole world and is fully georeferenced. Besides OpenStreetMap, however, almost any reliable and correctly georeferenced map can be used as a base map.

    If your base map is itself incorrectly georeferenced, the map you are georeferencing will also be positioned wrongly in space. After all, the wrong coordinate pairs will be retrieved from the map canvas and written to the GCPs. At first sight, such a wrong georeference does not necessarily stand out: the georeferenced map will fit nicely on the (problematic) base map. However, the problem will show up when these data are combined with other geodata.

  • Make sure that your control points are well and evenly spread over the whole map. If not, small deviations in the positioning of your control points can lead to large deviations further away from them. So also place control points near the edges and corners of the map, and avoid points that all lie (almost) on one line.

  • Create enough homologous points to reduce the impact of positioning errors and to better account for deviations in the map you are georeferencing. Each transformation type requires a minimum number of control points before georeferencing can be performed (see Transformation types). However, it is often wise to use more than this minimum.

  • Sometimes the situation shown on a historical map has changed so much that it is difficult to find homologous points on a present-day map. In such cases you can georeference in steps. First georeference an intermediate map that is closer in time to your historical map and therefore shows a more similar geographical situation. Then use this intermediate map as the base map for georeferencing your older map. You do not have to rely on a single reference map either. Because you take homologous points from the main map canvas, you can load several georeferenced layers there at the same time, for example a present-day map and one or more older maps, and place each control point on the layer where the corresponding point is easiest to recognise. In difficult cases this is good practice. Keep in mind that errors can accumulate: any inaccuracies in the reference maps will also affect the georeferencing of your older map.

If possible, use two screens when georeferencing. That way you can display the Georeferencer on one screen and the main QGIS window on the other. This makes it easier and more efficient to find and indicate homologous points.
