3.5 The QGIS project

QGIS project?

QGIS works on the principle that every work session is a project. If you save your project, you can close it and continue later exactly where you left off, without losing any work. The project file stores which data layers you use, how they are visualised, the scale and the part of the map you were looking at, the layouts you made, and so on.

QGIS projects are saved as.qgz files, which are usually small and are meant to be opened with QGIS. Older projects sometimes have the extension.qgs; QGIS opens both.

When you start QGIS, the welcome screen lets you choose: start a new, empty project or open an existing one.

Project menu and toolbar

In the menu bar, the Project menu offers everything you need to work with projects: saving your project, starting a new one, opening an existing one, and more. The most frequently used actions are also available in the Project Toolbar.

Of course, there are also more advanced project settings, for example the units used for measuring distances and areas (in Project ▸ Properties…). Later in this learning path, some other project settings will come up, such as the coordinate system of the project and the Layout Manager (see General: layouts).

Project ≠ data!

It is essential to repeat here that the data themselves are not saved in the project file: it only remembers the connections to the data sources.

After you have saved a project, you must never delete or rename your data files, otherwise the link to the data source that is stored in the project becomes invalid. If QGIS cannot find a data source when you open a project, it shows a window in which you can point to the new location of the file (Handle Unavailable Layers).

By default, QGIS saves the location of a data source as a relative path. This means that QGIS remembers the route from the folder where the project file is saved to the storage location of the data source.

For example, if your project file is saved in the folder ‘project X’ and the data source in the subfolder vector data, QGIS will only remember that it has to look for a subfolder vector data in the folder where the qgz file is. Because relative paths are used, you can move the whole folder ‘project X’ on your computer without changing the relative position of the project file and the data sources.

Using relative paths not only gives you a little more freedom to move whole folders on your computer; it also makes it easier to send QGIS projects together with their data to other people (for example in a zip file), or to share them through a file-sharing system with local synchronisation (for example Dropbox or OneDrive).

By default, QGIS saves data sources as relative paths. If you want to change this for a specific reason, you can do so in Project ▸ Properties… ▸ General, under Save paths.
