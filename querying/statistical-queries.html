8.4.1 Statistics of vector data

So far you have explored different ways to query geodata and focus on specific features. You can also query your data through statistical analysis. Rather than identifying specific features, statistical tools help you summarise and analyse data by calculating statistical values for an entire dataset or for groups of features. This page introduces statistical tools for vector data.

Querying attribute data statistically

Basic statistics for fields

The Basic statistics for fields tool lets you quickly calculate simple statistical values (such as mean, median, minimum, maximum, quantiles…) for a specific attribute field of a vector layer.

You open it via Processing Toolbox ▸ Vector analysis ▸ Basic statistics for fields. In the tool window, choose the layer and the field you want to analyse statistically, and click Run.

You do not see the result of the calculations immediately. Instead, a new link appears in the Results Viewer panel. Double-click it to open the report:

Statistics by categories

The Statistics by categories tool calculates statistics for groups of features. It uses the values in an attribute field to divide the features into categories.

For example, you have a point layer containing the major cities of the United States. Its attribute table includes fields with their population and the state they belong to. You can use Statistics by categories to group the cities by state and calculate population statistics for each group. In the tool window, configure the following parameters:

  • Input vector layer: select the layer you want to analyse (major_cities).
  • Field to calculate statistics on: select the field containing the values you want to analyse (POPULATION).
  • Field(s) with categories: select the field QGIS should use to group the features (STATE_ABBR).

The tool creates a new table with the statistics, one row per state. You can open this table via the Layers panel.

In the row of Texas, for example, you can read that the layer contains 263 Texan cities (count) with 19 772 314 inhabitants in total (sum), and that the largest has 2 304 580 inhabitants (max).

Querying geometries statistically

You can calculate statistics not only for attribute fields, but also for your geometries. Below are a few of the options, all in the Processing Toolbox.

  • You can apply Vector analysis ▸ Nearest neighbour analysis to a vector layer with point geometries. Among other things, it calculates the mean distance from each point to its nearest neighbouring point.

  • You can apply Vector analysis ▸ Overlap analysis to a polygon layer. For each polygon, it calculates how much of its area overlaps with another layer, as an area and as a percentage.

  • You can apply Vector general ▸ Join attributes by location (summary) to two layers. It calculates statistics for the features of one layer that overlap with the features of another layer, and writes them to a new layer. Chapter 12 comes back to this tool.

For example, for the Civil War battles (in EPSG:5070, a CRS in metres), Nearest neighbour analysis gives a mean distance of about 47 km to the nearest other battle. On the map, each black line connects a battle with the nearest other battle:
