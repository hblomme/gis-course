4.2.5 Graduated symbology

1. Automatic configuration

Graduated numeric values are numbers that can be placed on a scale from low to high. Unlike categories such as city or village, they do not form a limited list of separate values. Attribute fields often contain such graduated numeric values, for example the population (see POP1990, POP2000 and POP2010 in the example above) or the area of a feature. In practice, this means that each feature usually has a different value: it is, for example, highly unlikely that two states have exactly the same number of inhabitants. This kind of data needs a different way of visualising than a limited set of separate categories.

To give a layer a graduated symbology, open its Layer Properties, go to Symbology and choose Graduated in the list at the top (A). For point and line layers, you then choose under Method whether the classes differ in colour (default) or in size (points) / thickness (lines); polygon layers do not have this option. The rest of the setup works similarly to a Categorized symbology: you choose the attribute field (H) and set a few style options, such as the Color ramp (J).

A Graduated symbology divides the values into classes defined by a lower and an upper limit. All features in the same class get the same symbol. QGIS offers several methods to calculate these classes automatically. You decide how this is done:

  • you set how many classes you want (N)
  • you choose how QGIS calculates the class limits under Mode (M)

Below, we discuss the options in the Mode list.

  • Equal Count (Quantile): each class contains (as far as possible) the same number of features. The advantage is that no class dominates the map: each symbol appears about equally often. The downside is that the classes can have very different widths: values that are close to each other can end up in different classes, while very different values can share a class. In the example, each class contains 10 states, but the last class runs from 9 to 37.3 million.

  • Equal Interval: QGIS divides the range of values into classes of the same width. It calculates this width by dividing the difference between the highest and the lowest value by the number of classes you asked for. The advantage is that each step from one class to the next stands for the same difference in value, which makes the map easy to interpret. The downside is that with unevenly spread values, one class can contain almost all features, while other classes stay (nearly) empty. In the example, each class is (37.3 − 0.6 million) / 5 ≈ 7.4 million wide, and 38 of the 50 states end up in the first class.

  • Fixed Interval: this works like Equal Interval, but the other way round: you set the width of the classes yourself under Interval size, and QGIS calculates how many classes are needed to get from the smallest to the largest value. The number under Classes is not used. In the example, an interval size of 5 million inhabitants gives 8 classes, two of which are empty.

  • Logarithmic Scale: the class limits follow a logarithmic scale: each class is wider than the one before. QGIS places the limits at round values on that scale. As a result, the number of classes can differ from the number you asked for. The advantage is that this method suits values that range from very small to very large, with many small values and a few large ones. In the example, QGIS makes 4 classes, with limits at 3.2 million (106.5), 10 million (107) and 31.6 million (107.5); the last class ends at 100 million.

  • Natural Breaks (Jenks): QGIS looks for groups (clusters) of values that lie close together: it makes the differences between the values within each class as small as possible, and the differences between the classes as large as possible. The class limits therefore usually fall in the gaps between such clusters. The advantage is that the classes follow how the values are actually distributed. The downside is that the classes have different widths, which makes the map harder to interpret. In the example, the limits lie at 3.1, 6.8, 12.9 and 25.3 million.

  • Pretty Breaks: QGIS divides the range of values by the number of classes you asked for, and rounds this class width to an easy-to-read number. The result is a fixed class width with round numbers as limits between the classes. Because of this rounding, the final number of classes can differ from the number you asked for. The advantage is a legend that is easy to read. In the example, 36.8 million / 5 ≈ 7.4 million is rounded to 10 million, which gives limits at 10, 20 and 30 million and 4 classes instead of 5.

  • Standard Deviation: the classes show how far the values lie above or below the mean. The class limits lie at fixed steps from the mean, expressed in standard deviations, for example steps of 1, 0.5 or 0.2 standard deviation. In QGIS, this method only works well when the values are spread roughly symmetrically around the mean, as in a normal distribution. With a strongly skewed distribution, such as the populations in the example, this method is in practice unusable.

2. Manual configuration

You can also build the classes yourself. Click the green plus symbol under the list of classes (K): QGIS adds a new class, and you set its lower and upper limit by double-clicking it in the Values column. If you started from a calculated classification, you can adjust its limits in the same way. In the Histogram tab (next to Classes) you can also see how the values are spread, and move the class limits there.

If you change the number of classes or the Mode after adjusting classes by hand, QGIS calculates all classes again, and your manual changes are lost.
