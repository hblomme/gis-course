Solution 3: Beguinages in the Low Countries

This solution follows the steps of the exercise. The screenshots use Belgian Lambert 72 (EPSG:31370).

Part A: Mapping the dioceses and the beguinage courts

1. Layers in Belgian Lambert 72

Drag beguinages.gpkg into QGIS and add all five layers. The data are in ETRS89-LAEA (EPSG:3035), a coordinate system for the whole of Europe. For Belgium, Belgian Lambert 72 (EPSG:31370) is a good choice (see Projected coordinate systems).

Set the project to EPSG:31370 (bottom right in the status bar). To convert the layers themselves, open Processing Toolbox ▸ Vector general ▸ Reproject layer for each layer, choose EPSG:31370 as Target CRS and save the result in a new GeoPackage. With Run as Batch Process… you convert all five layers at once. Export ▸ Save Features As… works as well.

2. Seats of bishops and archbishops

In the Layer Properties of seats, choose Categorized on type and click Classify. Double-click each symbol to give it its own shape and size (Simple Marker ▸ Shape, Size): in the map below a large black star for archdiocese and a small square for diocese. See Categorized symbology.

3. Diocese names with rule-based labels

On the Labels tab of dioceses, choose Rule-based Labeling and add two rules (see Rule-based styling). The archdioceses are the dioceses whose name is the same as the value in archdiocese: Canterbury, Cologne, Mainz, Reims, Rouen and Trier.

  • Archdiocese: rule "name" = "archdiocese", value upper("name") (capitals), bold, a little larger.
  • Diocese: Else rule, value "name", italic.

4. How certain are the data?

In the Layer Properties of beguinages, choose Rule-based with three rules (see Rule-based styling):

  • Exact years (green dot): "founded_accuracy" = 'exact' AND "closed_accuracy" = 'exact'
  • Other (orange dot): NOT ("founded_accuracy" = 'exact' AND "closed_accuracy" = 'exact')
  • Location not certain (an exclamation mark): "position" = 'approximate'. For the symbol, choose the symbol layer type Font Marker and type !.

Keep the exclamation mark rule last, so that it lies on top of the dot. The rule for the orange dots is the opposite of the green rule, so that every beguinage court gets a dot, also when the exclamation mark rule applies to it.

27 beguinage courts have an exact founding year and an exact closing year. 12 have a location that is not certain.

Part B: Highlighting and extracting beguinage courts

1. Dedicated to the Virgin Mary

Many beguinage courts are dedicated to more than one saint, for example “Virgin Mary / St. Agnes / St. Catherine”. Open Select Features by Expression and use the operator LIKE with % before and after the name: % stands for any number of characters, so that you also find these combinations (see Logical operators). Search for the full name “Virgin Mary”, so that Mary Magdalen is left out:

"dedication" LIKE '%Virgin Mary%'

10 beguinage courts are dedicated (also) to the Virgin Mary, among them “St. John and Virgin Mary” and “Consolation of Virgin Mary”. One of them, “Virgin Mary / St. Mary Magdalen”, is dedicated to both.

2. Beguinage courts in the ecclesiastical province of Reims

First select the dioceses of the ecclesiastical province of Reims, for example with Select Features by Expression on dioceses and "archdiocese" = 'Reims' (12 dioceses). Then open Processing Toolbox ▸ Vector selection ▸ Extract by location: extract features from beguinages that are within the features from dioceses, with Selected features only ticked (see Automated selections). Save the result as beguinages_reims. It contains 46 beguinage courts.

Extract by location makes the new layer in one step. With Select by location, you first select the beguinage courts and then save them with Export ▸ Save Selected Features As… (as in the next task).

Part C: The beguinage courts through time

1. Lifespan

Open the Field Calculator on beguinages, create a new field lifespan of type Integer (32 bit) and subtract the two years (see The Field Calculator):

"closed" - "founded"

For the beguinage courts that still exist, the closing year is empty, so the result is NULL. Select them with Processing Toolbox ▸ Vector selection ▸ Select by attribute: field existing, operator =, value true (see Automated selections). Open the Field Calculator again, tick Only update … selected features, choose Update existing field lifespan, and subtract the founding year from the current year. You can type the current year yourself, or use year(now()): then the lifespan stays up to date.

year(now()) - "founded"

2. In present-day Belgium

  1. Open Processing Toolbox ▸ Vector selection ▸ Select by location: select features from beguinages that are within the features from belgium (see Automated selections). 54 of the 88 beguinage courts are selected.
  2. Open the Field Calculator on beguinages, tick Only update … selected features, create a new field in_belgium of type Boolean and enter true as the expression (see The Field Calculator).
  3. Invert the selection with Edit ▸ Select ▸ Invert Feature Selection: now the 34 beguinage courts outside Belgium are selected.
  4. Open the Field Calculator again, tick Only update … selected features, choose Update existing field in_belgium and enter false.

The function is_selected() does steps 2 to 4 in one go. Keep the selection of step 1, untick Only update … selected features, and use is_selected() as the expression for the new field: it gives true for the selected beguinage courts and false for the others.

3. More than 500 years

Select the beguinage courts with "lifespan" > 500 and save them with Export ▸ Save Selected Features As… as a new layer, for example beguinages_500. The fields lifespan and in_belgium go along. In the Layer Properties of the new layer, choose Rule-based with four rules (see Rule-based styling):

  • Present-day Belgium (a dot in one colour): "in_belgium"
  • Elsewhere (a dot in another colour): NOT "in_belgium"
  • Still existing (a larger circle, without fill): "existing"
  • UNESCO World Heritage (an even larger star, without fill): "unesco"

A beguinage court that meets several rules gets all their symbols. Because the circle and the star have no fill, the dot stays visible inside them. The rule NOT "in_belgium" gives every beguinage court outside Belgium its dot, also when another rule applies to it.

Part D: Calculating new information

1. Area of the dioceses

Open the Field Calculator on dioceses, create a new field area_km2 of type Decimal number (real) and use $area / 1000000 (see The Field Calculator).

$area calculates the area on the ellipsoid of the project, in m², so the result is reliable for dioceses far from Belgium too. QGIS can only do this correctly when the layer has the right CRS: after task A1, all layers are in Belgian Lambert 72. Check the ellipsoid in Project ▸ Properties ▸ General under Measurements (see Using geometric properties).

For the mean and the median, open Processing Toolbox ▸ Vector analysis ▸ Basic statistics for fields on area_km2 (see Statistical queries). The mean is about 7 930 km², the median about 5 520 km².

2. Statistics per archdiocese

Open Processing Toolbox ▸ Vector analysis ▸ Statistics by categories, with dioceses as input layer, area_km2 as the field to calculate statistics on and archdiocese as the field with categories (see Statistical queries).

In the new table, the row of Reims shows 12 dioceses with a mean area of about 4 770 km².

3. Distance to the nearest beguinage court

Open Processing Toolbox ▸ Vector analysis ▸ Nearest neighbour analysis on beguinages (see Statistical queries). The tool measures, for each beguinage court, the distance to the nearest other one, and gives the mean of these distances. The layer must be in a CRS in metres, which it is after task A1. The Observed mean distance is about 13 400 m: on average, the nearest other beguinage court lay about 13 km away, a few hours on foot.

4. Distance to the archbishop of Reims

Open the Field Calculator on beguinages_reims and create a new field dist_reims of type Decimal number (real). get_feature fetches the seat of Reims from the layer seats, and distance measures the distance in metres (see Retrieving features):

distance(@geometry, geometry(get_feature('seats', 'name', 'Reims'))) / 1000

Sort the attribute table on dist_reims: the nearest beguinage court is Avesnes-sur-Helpe, at about 105 km from Reims.

In task 3, the mean distance from a beguinage court to the nearest other beguinage court was about 13 km. The beguinage court nearest to Reims lies eight times as far from the seat of the archbishop. The beguinage courts lie close to each other, in the towns of Flanders, Hainaut and Brabant, but far from Reims.
