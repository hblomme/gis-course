Solution 3: Beguinages in the Low Countries

This solution follows the steps of the exercise. The screenshots use Belgian Lambert 72 (EPSG:31370).

Part A: Highlighting and extracting beguinage courts

1. Layers in Belgian Lambert 72

Drag beguinages.gpkg into QGIS and add all five layers. The data are in ETRS89-LAEA (EPSG:3035), a coordinate system for the whole of Europe. For Belgium, Belgian Lambert 72 (EPSG:31370) is a good choice (see Projected coordinate systems).

Set the project to EPSG:31370 (bottom right in the status bar). To convert the layers themselves, open Processing Toolbox ▸ Vector general ▸ Reproject layer for each layer, choose EPSG:31370 as Target CRS and save the result in a new GeoPackage. With Run as Batch Process… you convert all five layers at once. Export ▸ Save Features As… works as well.

2. Dedicated to the Virgin Mary

Many beguinage courts are dedicated to more than one saint, for example “Virgin Mary / St. Agnes / St. Catherine”. Open Processing Toolbox ▸ Vector selection ▸ Select by attribute on beguinages and choose the field dedication, the operator contains and the value Virgin Mary (see Automated selections). Contains also finds these combinations. Search for the full name “Virgin Mary”, so that Mary Magdalen is left out. Upper and lower case count: type Virgin Mary exactly like this.

After chapter 9 you can also select them with an expression in Select Features by Expression (see Text fields). % stands for any number of characters:

"dedication" LIKE '%Virgin Mary%'

10 beguinage courts are dedicated (also) to the Virgin Mary, among them “St. John and Virgin Mary” and “Consolation of Virgin Mary”. One of them, “Virgin Mary / St. Mary Magdalen”, is dedicated to both.

3. Founded before 1250, outside present-day Belgium

First open Processing Toolbox ▸ Vector selection ▸ Select by attribute on beguinages: field founded, operator <, value 1250. 29 beguinage courts are selected.

Then open Processing Toolbox ▸ Vector selection ▸ Select by location: select features from beguinages that are disjoint from the features from belgium, and under Modify current selection by choose selecting within current selection (see Automated selections).

9 of the 29 early beguinage courts lie outside present-day Belgium: Aachen (Saint Matthias), Aardenburg, Cambrai, Douai, Hesdin, Le Quesnoy, Lille, Middelburg and Valenciennes.

4. UNESCO World Heritage

Open Processing Toolbox ▸ Vector selection ▸ Extract by attribute on beguinages: field unesco, operator =, value 1. unesco is a Boolean field: in this tool you type TRUE as 1 and FALSE as 0. With the value true the tool finds nothing. Save Extracted (attribute) as for example beguinages_unesco (13 beguinage courts) and Extracted (non-matching) as beguinages_other (75): one run gives you both layers.

Then open Processing Toolbox ▸ Vector analysis ▸ Basic statistics for fields on the fields founded and closed of each new layer (see Statistical queries). The statistics of closed, for the UNESCO beguinage courts (left) and the others (right):

UNESCO Other
Founding year: mean 1266.9 1281.7
Founding year: median 1245 1265
Closing year: mean 1946.3 1664.4
Closing year: median 1971 1620.5
Earliest closing year 1856 1310

The founding years hardly differ: the beguinage courts on the UNESCO list are not much older than the others. The closing years differ a lot. All of them existed until the second half of the 19th century or later, and three still exist (their closing year is empty). They are on the list because they survived, not because they were the first.

Part B: Calculating new information

1. Lifespan

Open the Field Calculator on beguinages, create a new field lifespan of type Integer (32 bit) and subtract the two years (see The Field Calculator):

"closed" - "founded"

For the beguinage courts that still exist, the closing year is empty, so the result is NULL. Select them with Processing Toolbox ▸ Vector selection ▸ Select by attribute: field existing, operator =, value 1 (see Automated selections). Open the Field Calculator again, tick Only update … selected features, choose Update existing field lifespan, and subtract the founding year from the current year. You can type the current year yourself, or use year(now()): then the lifespan stays up to date.

year(now()) - "founded"

2. Area of the dioceses

Open the Field Calculator on dioceses, create a new field area_km2 of type Decimal number (real) and use $area / 1000000 (see The Field Calculator).

$area calculates the area on the ellipsoid of the project, in m², so the result is reliable for dioceses far from Belgium too. QGIS can only do this correctly when the layer has the right CRS: after task A1, all layers are in Belgian Lambert 72. Check the ellipsoid in Project ▸ Properties ▸ General under Measurements (see Units of measurement).

3. Statistics per archdiocese

Open Processing Toolbox ▸ Vector analysis ▸ Statistics by categories, with dioceses as input layer, area_km2 as the field to calculate statistics on and archdiocese as the field with categories (see Statistical queries).

The new table has one row per ecclesiastical province. The row of Reims shows 12 dioceses with a mean area of about 4 770 km².

4. Distance to the nearest beguinage court

Open Processing Toolbox ▸ Vector analysis ▸ Nearest neighbour analysis on beguinages (see Statistical queries). The tool measures, for each beguinage court, the distance to the nearest other one, and gives the mean of these distances. The layer must be in a CRS in metres, which it is after task A1. The Observed mean distance is about 13 400 m: on average, the nearest other beguinage court lay about 13 km away, a few hours on foot.

5. Beguinage courts in the ecclesiastical province of Reims

First select the dioceses of the ecclesiastical province of Reims, for example with Processing Toolbox ▸ Vector selection ▸ Select by attribute on dioceses: field archdiocese, operator =, value Reims (12 dioceses). Then open Processing Toolbox ▸ Vector selection ▸ Extract by location: extract features from beguinages that are within the features from dioceses, with Selected features only ticked (see Automated selections). Save the result as beguinages_reims. It contains 46 beguinage courts.

Extract by location makes the new layer in one step. With Select by location, you first select the beguinage courts and then save them with Export ▸ Save Selected Features As….

6. Distance to the archbishop of Reims

Open the Field Calculator on beguinages_reims and create a new field dist_reims of type Decimal number (real). get_feature fetches the seat of Reims from the layer seats, and distance measures the distance in metres (see Retrieving features):

distance(@geometry, geometry(get_feature('seats', 'name', 'Reims'))) / 1000

Sort the attribute table on dist_reims: the nearest beguinage court is Avesnes-sur-Helpe, at about 105 km from Reims.

In task 4, the mean distance from a beguinage court to the nearest other beguinage court was about 13 km. The beguinage court nearest to Reims lies eight times as far from the seat of the archbishop. The beguinage courts lie close to each other, in the towns of Flanders, Hainaut and Brabant, but far from Reims.

Part C: Mapping the dioceses and the beguinage courts

1. Seats of bishops and archbishops

In the Layer Properties of seats, choose Categorized on type and click Classify. Double-click each symbol to give it its own shape and size (Simple Marker ▸ Shape, Size): in the map below a large black star for archdiocese and a small square for diocese. See Categorized symbology.

2. Diocese names with rule-based labels

On the Labels tab of dioceses, choose Rule-based Labeling and add two rules (see Rules). The archdioceses are the dioceses whose name is the same as the value in archdiocese: Canterbury, Cologne, Mainz, Reims, Rouen and Trier.

  • Archdiocese: rule "name" = "archdiocese", value upper("name") (capitals), bold, a little larger.
  • Diocese: Else rule, value "name", italic.

3. How certain are the data?

In the Layer Properties of beguinages, choose Rule-based with three rules (see Rules):

  • Exact years (green dot): "founded_accuracy" = 'exact' AND "closed_accuracy" = 'exact'
  • Other (orange dot): NOT ("founded_accuracy" = 'exact' AND "closed_accuracy" = 'exact') OR "closed_accuracy" IS NULL
  • Location not certain (an exclamation mark): "position" = 'approximate'. For the symbol, choose the symbol layer type Font Marker and type !.

Keep the exclamation mark rule last, so that it lies on top of the dot. The rule for the orange dots is the opposite of the green rule, so that every beguinage court gets a dot, also when the exclamation mark rule applies to it. The beguinage courts that still exist have no closing year, so closed_accuracy is empty. For them the comparison gives NULL, and NOT NULL stays NULL (see NULL values). Without OR "closed_accuracy" IS NULL three beguinage courts would get no dot at all: Ghent (Our-Lady Ter Hooyen), Kortrijk and Sint-Amandsberg.

27 beguinage courts have an exact founding year and an exact closing year. 12 have a location that is not certain.

4. More than 500 years

Add a fourth rule to the rules of task 3: More than 500 years, "lifespan" > 500, with a dot of the same size, without fill and with a red outline. Put it below the green and orange rules, so that the red circle lies on top of the dot, and above the exclamation mark rule.

A beguinage court that meets several rules gets all their symbols. 42 beguinage courts existed for more than 500 years.
