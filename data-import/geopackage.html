7.1 Managing layers in GeoPackages

On Common file formats in QGIS you learned what a GeoPackage is: a single database file that can hold several layers. This page shows how to use a GeoPackage in practice:

  • how to create a GeoPackage
  • how to save layers in a GeoPackage
  • how to store layer styles in a GeoPackage
  • how to rename or delete layers in a GeoPackage

The image below shows where you find most of these options in QGIS. The letters are used in the text below.

Creating a GeoPackage

You already know how to save a layer as a GeoPackage. This is the default format in QGIS when creating a new vector layer. In fact, when you do this, you create not only a new layer but also an entirely new database that stores it.

You can also start with an empty GeoPackage database and add layers to it later. One way to do this is to right-click GeoPackage in the Browser panel (B) and choose Create Database….

Saving layers in a GeoPackage

New layers

You can add a new, empty layer to a GeoPackage with the New GeoPackage Layer button on the Data Source Manager Toolbar (A) (or Layer ▸ Create Layer ▸ New GeoPackage Layer…). Next to File name, select your existing GeoPackage and give the layer a name under Table name. Then click OK and choose Add New Layer. You will learn how to fill a new empty layer from scratch in Manual vectorising.

Existing layers

There are several ways to save existing layers in a GeoPackage.

GeoPackage section in the Browser panel

The easiest method is to drag one or more layers onto your GeoPackage in the Browser panel (B). Alternatively, you can right-click your GeoPackage there and choose Import Vector Layer…. An import window will pop up where you can set the Table name, the Output CRS and the fields to include.

Save Features As…

Another option is to export an existing layer into a GeoPackage. Right-click it in the Layers panel (C) and choose Export ▸ Save Features As… (vector) or Export ▸ Save As… (raster). Pay attention: for rasters, GeoPackage is not the default export format.

  1. Under Format, select GeoPackage.
  2. Next to File name, click the … button and select your existing GeoPackage, or type a name for a new one.
  3. Under Layer name, type a new name for this layer.
  4. Click OK. QGIS adds the layer to the existing file. Only if a layer with the same name already exists in the file does QGIS ask what to do (for vector layers, the options are Overwrite File, Overwrite Layer or Append to Layer).

Be careful when choosing Overwrite File: QGIS deletes the entire GeoPackage, including all its layers, and creates a new one containing only the layer you are saving. Overwrite Layer, on the other hand, replaces only the layer with the same name. Append to Layer adds all features of the layer as new features. QGIS does not check whether they are already in the layer, so appending twice gives duplicates.

Package layers

With the processing tool Package layers, you can store one or more layers at once in a new or an existing GeoPackage, together with their active style. This tool only works for vector layers.

  1. Load the layers into your project.
  2. Open the Processing Toolbox (D) (Processing ▸ Toolbox) and choose Database ▸ Package layers (or type package in the search box).
  3. Under Input layers, click the … button and select all the layers you want to store.
  4. Leave Overwrite existing GeoPackage unticked if you want to add the layers to an existing GeoPackage. If a layer with the same name already exists, it will be replaced. If you do tick this option, QGIS first deletes the existing database, including all the layers it contains.
  5. Leave Save layer styles into GeoPackage ticked to store the active style of each layer along with its data. Only the active style is packed, the others are not stored with it.
  6. Under Destination GeoPackage, choose Save to File… and select a new or an existing GeoPackage.
  7. Click Run.

Using the GeoPackage layers in your project

QGIS does not change your original layers. It only makes copies of them in GeoPackage format. If one of the originals was loaded in your QGIS project, it stays there. The copies are not loaded, unless Add saved file to map was ticked in the export window.

If you want to use your newly created GeoPackage layers in your project, you have to replace the originals:

  • Remove the original layers from the Layers panel and add the corresponding layers from the GeoPackage in the Browser panel (B).
  • Alternatively, right-click the original layer and choose Change Data Source… to point it to the corresponding layer in the GeoPackage. This preserves the layer’s style and other settings.

Storing styles in a GeoPackage

Normally, how a layer is styled is stored in your project file, not with the data itself. If you add a GeoPackage layer to another project, or send the GeoPackage to someone else, the layer appears with a random default style. You can avoid this by storing the style inside the GeoPackage.

For any layer in your GeoPackage, you can do this as follows (see also Saving and reusing styles):

  1. Right-click the layer in the Layers panel and choose Styles ▸ Save Style….
  2. Under Save style, choose In datasource database.
  3. Give the style a name. Optionally, tick Use as default style for this layer if you want QGIS to use this style when the layer is imported. Then click OK.

You can save several styles for the same layer in your GeoPackage.

Renaming and deleting layers in a GeoPackage

In the Browser panel (B), open the GeoPackage (small arrow in front of it) and right-click a layer. Under Manage, you find the options to rename and to delete the layer. You can rename fields there too: open the layer and its Fields, and right-click a field.

A layer that you delete from a GeoPackage cannot be recovered, so be careful.
