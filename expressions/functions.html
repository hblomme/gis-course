9.3.4 Text and math functions

Functions in QGIS expressions

Functions let you do more with your data than simply read or compare it. They are ready-made operations that take an input, such as a field value, and return a result based on it. You can use them for example to change text values, round a number or compare a value with the average across all features.

A simple example: in a layer containing the major cities of the United States, upper("NAME") converts the name of every city to capital letters. For Chicago, it gives CHICAGO.

QGIS provides many functions for working with text, numbers, geometries and other types of data. You can find them in the central panel (B) of the Expression Builder and the Field Calculator, together with the available fields. Most functions follow the same basic syntax: a function name followed by one or more arguments in brackets.

function_name(argument_1, argument_2)

An argument is the input a function needs to perform its operation.

Remember that QGIS evaluates an expression for each feature separately. When you use a field as an argument, QGIS uses the field value of the current feature. You can also enter a fixed value, which QGIS then uses for every feature.

Syntax and arguments

The arguments a function requires depend on what it does. Some functions expect a single value, while others need several arguments of different types, such as numbers or geometries. When a function requires multiple arguments, separate them with commas and pay attention to their order.

You do not need to memorise these requirements. The function documentation in QGIS tells you exactly what each function needs (C).

Documentation

For each function the documentation shows what it does (C1), its syntax (C2), the required type of each argument (C3) and examples showing how to use it and what output to expect (C4).

You can use this information whenever you are unfamiliar with a function. Let’s look at three examples.

1. upper() – changing text to capital letters

The function upper() requires one argument: a text value (string). It returns that text in capital letters.

2. round() – rounding a number

The function round() requires a number. You can also provide a second argument to specify the number of decimal places.

In the syntax, square brackets [ ] indicate an optional argument. If you leave it out, QGIS rounds to a whole number.

For Chicago, round("POPULATION" / 1000000, 1) returns 2.7. The population is first converted to millions and then rounded to one decimal place.

3. replace() – replacing part of a text

The function replace() requires three text arguments:

  • the original text;
  • the part you want to replace;
  • the replacement text.

For St. Louis, replace("NAME", 'St.', 'Saint') returns Saint Louis.

The documentation also shows another version of this function that uses a map. We will not use that version here.

You can use the function list to explore what QGIS has to offer. If you know what you want to do, type a related term, such as average or round, in the search box at the top of the function list (B). Browse the results and use the documentation to check what each function does and whether it suits your needs.

This means you can find and learn to use almost any function yourself. In the following sections, we will look at a selection of functions that you are likely to use regularly.

String functions

String functions work with text values. You can find them in the String group of the central function list (B).

Here are some common operations, with examples using the city of St. Louis.

  • Changing the case: upper(text) converts a text to uppercase, lower(text) to lowercase, and title(text) capitalises the first letter of each word. lower("NAME") gives st. louis, title('st. louis') gives St. Louis.
  • Cleaning up a text: trim(text) removes spaces at the start and end of a text. trim(' St. Louis ') gives St. Louis without the spaces.
  • Changing a text: replace(text, before, after) replaces part of a text with another text. replace("NAME", 'St.', 'Saint') gives Saint Louis.
  • Combining texts: concat(text1, text2, …) joins texts into one text. concat("NAME", ' (', "STATE_ABBR", ')') gives St. Louis (MO).
  • Counting characters: length(text) returns the number of characters in a text. length("NAME") gives 9.

You can also use the result of a function in a condition. For example length("NAME") > 20 identifies cities with names longer than 20 characters.

Math functions

Math functions perform calculations on numerical values. You can find them in the Math group of the central function list (B).

A common use is rounding numbers. The following examples use Chicago, which has a population of 2 746 388.

  • Rounding to a specified number of decimals: round(number, decimals) rounds a number to the number of decimal places you specify. For example round("POPULATION" / 1000000, 1) returns 2.7.
  • Rounding up: ceil(number) rounds a number up to the nearest whole number. For example ceil("POPULATION" / 1000000) returns 3.
  • Rounding down: floor(number) rounds a number down to the nearest whole number. For example floor("POPULATION" / 1000000) returns 2.

Aggregate functions

Sometimes you want to compare a feature’s value with values from all other features in the layer. Aggregate functions let you do this. You can find them in the Aggregates group. Common examples are mean(), sum() and maximum().

Unlike the functions we have seen so far, aggregate functions calculate a result using values from multiple features. Let’s look at an example.

Suppose you want to compare each city’s population with the average population of all cities in the layer. You can do this with the following expression:

"POPULATION" - mean("POPULATION")

In the Field Calculator you can store the result in a new field, here POP_DIFF.

Notice that the field POPULATION appears twice in the expression, but it is used differently each time.

Before the minus sign, QGIS uses the population of the current feature. Inside mean(), it calculates the average population across all features. The expression therefore subtracts the overall average from each city’s population.

Replacing NULL values

As you learned on the previous page, attribute fields can contain NULL values, meaning that no value is available. This can prevent you from performing calculations or comparisons with those values. Sometimes, you may want to replace missing values with a value such as 0. QGIS provides the function coalesce() for this purpose.

Its documentation explains that you can provide any number of arguments. The function returns the first argument that is not NULL.

Consider a layer of the US states, with the number of seats each had in the House of Representatives in 2010 stored in the REPR2010 field. For the District of Columbia and the territories, this field is NULL. You can use coalesce("REPR2010", 0) to replace these NULL values with 0 while leaving existing values unchanged.

You can also use coalesce() in calculations. For example coalesce("REPR2010", 0) - coalesce("REPR1990", 0) calculates the change in the number of seats between 1990 and 2010, treating NULL values as 0. This returns 0 instead of NULL for the District of Columbia.

You have now explored several functions for working with text and numbers. Later in this chapter you learn the functions for geometries and for other layers and features.
