6.2.3 Legend, scale bar and north arrow

Legend

A legend helps readers understand what the symbols on your map represent. It shows each layer with its name and associated symbology. For categorized or graduated layers, each class is listed separately.

If your layout contains several maps, first make sure that the legend is linked to the right map. You set this under Main Properties (I1) in the legend’s Item Properties (Map). In the same section, you also set the arrangement of the legend: should the text labels appear before or after the symbols? If Resize to fit contents is ticked, the width and height of the legend are adapted automatically, so that all legend items just fit in. This is important if you want to show a background or a frame around the legend.

In the other sections of a legend’s Item Properties, you can further configure its appearance and choose which layers should be mentioned. For the latter, you will find three options under Legend Items (I2):

  1. Synchronize to All Project Layers: the legend shows all layers of your project, also the layers you have switched off in the Layers panel.
  2. Synchronize to Visible Layers: the legend only shows the layers that are switched on in your project. If the legend is linked to a map that follows a map theme, it shows the layers that are active in this theme instead. With this option, the inactive layers are still listed in the Item Properties under Legend Items (I3), but they no longer appear in the legend on the layout itself.

With both synchronize options, the legend is updated automatically when you change the style or the name of a layer.

  1. Manual: the list of layers shown in the legend is no longer kept in sync with your project. You decide yourself which layers the legend shows, by adding and removing items with the plus and minus buttons (I4). By default, the names and styles of these layers still follow the changes in your project or map theme. With Manual, however, you can override both: double-click a legend item, or select it and click Edit selected item properties , to change its label (I6) or to set a Custom Symbol (I7). Once you have done this, your manual settings always overrule later changes to the style or name.

To fine-tune your legend further, QGIS offers the option to Only show items inside linked maps (I5). QGIS then removes every layer, or class of a layer, of which no features are visible in the linked map. That way your legend never shows unnecessary items.

Pay attention to the labels in your legend. By default, a legend item shows the layer name as it appears in the Layers panel, and these are not always suitable for a published map (for example file or system names). When working with legends, make sure your layers have clear names. If your legend needs a label other than the layer name, you can easily set it with Manual. With the synchronize options this is possible too, but you have to use the Expression Builder.

For the appearance of the legend, you set, for example, the font and font size under Fonts and Text Formatting, the number of columns under Columns, the size of the symbols under Symbol, and the space between legend items and between text and symbols under Spacing.

Scale bar

If you add a scale bar to your map, QGIS automatically makes sure that it shows the correct scale. If you later change the scale of your map item, the scale bar adapts automatically.

Make sure that the map the scale bar is linked to uses a suitable coordinate system (see Coordinate reference system), so that the scale bar is as reliable as possible for the whole map.

QGIS calculates the width of the scale bar for you, but you still choose how it looks:

  • In the Item Properties of the scale bar, under Main Properties (I8), you first choose which map you want to show the scale of (important if your layout contains several maps). You can also choose a general scale bar style there. The image below gives an overview of the options.

  • Under Units (I9), you choose the unit of the scale bar (Scalebar units, for example ‘Kilometers’) and its label on the scale bar (Label for units, for example ‘km’). Normally, the Label unit multiplier is 1. On the rare occasion that the unit you want is not in the list, you can use the multiplier. For hectometres, for example, choose Meters with a multiplier of 100. Under Method, you choose where on the map the scale bar distance is measured. In a projected CRS, the scale can differ across the map.

  • Under Segments (I10) you then decide how many parts (or segments) your scale bar has and how many of them are shown to the left and right of the zero point. You also set how wide each segment is.

  • Finally, under Appearance (I11) you can adjust some stylistic elements (for example position of the labels, font and font size, line and fill symbols…).

North arrow

The last item type discussed here is the north arrow. When you add a north arrow, QGIS adds an image of an arrow to your layout. You can replace this image with any other: QGIS offers a wide range of arrow images in its SVG library (SVG browser), but in principle you can choose any image at all, for example one from your computer.

What makes a north arrow useful is that its rotation can be linked to a map item. Under Image Rotation, make sure that Sync with map is ticked and choose the map it should follow. For example, if you rotate the map 90° clockwise (so that west is at the top), the north arrow turns too and points to the right instead of up.

Under North alignment, you choose where the arrow should point to: Grid North (the direction of the map’s vertical grid lines) or True North (the direction of the geographic North Pole).

On smaller-scale maps the direction of true north can differ substantially from place to place. In that case, a single north arrow is an approximation: it is only correct for the centre of the map. While grid north can diverge from true north, it is the same everywhere on the map.
