6.2.2 Map items

What a map item shows

As you learned in General: layouts, a Print Layout is simply a page on which you can add items. This means you also have to add the map frame itself as an item. When you add a new map item, it initially reflects the map as it appears in the map canvas of the main QGIS window: it displays the same area (adjusted to fit the shape of the map item) and uses the same layer visibility and styles.

From that moment on, by default, map items in the layout continue to reflect changes to layer visibility and symbology in the main QGIS window. However, changes to the map canvas extent do not affect them. Panning or zooming in the main QGIS window, for example, does not change the area or scale displayed in the maps on your layout.

The following examples illustrate this distinction:

By default, map items in the layout…
are updated (follow the map canvas) when you: remain unchanged (do NOT follow the map canvas) when you:
make a layer (in)visible in the Layers panel pan the map (by dragging or re-centring it)
change the symbology of a layer, for example its colour zoom in or out, thereby changing the scale
add labels or change their appearance (font…) make a selection
add diagrams to your layer
remove a layer or add a new layer to your project
update a layer’s data

Sometimes the automatic updates only become visible in your layout after you have clicked refresh or Update Preview.

Turning off automatic updates

Automatic updates of your map in the layout environment can be useful, but in certain cases they are not desirable.

For example, suppose you want to display two maps on your layout page: one showing a wider area for an overview, and another zooming in on a specific region to show more detail. Some layers containing detailed information should appear on the detail map only, while the overview map should show more general labels. In this case, you need two different map configurations at the same time.

Lock layers and Lock styles for layers

In such cases, you can turn off automatic updates in the layout environment. To do so, map items have two options under the Layers group (I2) in their Item Properties: Lock layers and Lock styles for layers.

When you select Lock layers, the map item retains the layer visibility as it is at that moment. Subsequent changes to layer visibility (using the checkboxes in the Layers panel) will no longer be reflected in the map item.

Similarly, Lock styles for layers preserves the layer styles as they are when you enable the option. Any later changes to symbology (such as colours and shapes), labels or diagrams will not be applied to the map item. This option is only available once Lock layers is ticked.

You cannot edit the styles of a locked map item. As soon as you untick Lock layers or Lock styles for layers, the map item is synchronised with the current settings in the map canvas. This means that any custom configuration you have locked in is lost.

Follow map theme

A more flexible way to keep your layout maps independent of the active map canvas is to use map themes. As you saw in Saving and reusing styles, a map theme stores which layers are visible and which style is active for each. QGIS allows you to assign such a theme to a map item in the print layout. This way, you can both control the map item’s display independently of the map canvas and easily update its appearance by editing the corresponding map theme.

The example layout in the image above was created using two separate map themes. The detail map follows the map theme Detail map, the overview map follows the map theme Overview map.

The Overview map theme shows the towns of Flanders, using circles to represent their population. To make the Liberty of Bruges stand out, it is displayed in dark red without an outline, while the Low Countries are shown in blue-grey with region names.

The Detail map theme, on the other hand, shows the towns within the Liberty of Bruges. Here, the Liberty of Bruges is displayed in a soft clay colour, while the Low Countries are light grey without region names, making the town names easier to read.

To do this:

  1. In your main QGIS window, give each layer that should look different a style for each map (right-click the layer in the Layers panel, Styles ▸ Add…) and configure it as desired.
  2. At the top of the Layers panel in your main QGIS window, choose Manage Map Themes ▸ Add Theme… to save a map theme for each map.
  3. In your Print Layout window, select a map item and go to its Item Properties. Under Layers, tick Follow map theme and choose the map theme of this map.
  4. Do the same for the other map item.

Scale and extent

To set the desired scale and extent of a map item, go to the Item Properties panel and adjust the settings under Main Properties (I1, Scale) and Extents (I3), respectively. You can also move the map content within the item using the Move item content tool , as explained in General: layouts.

Coordinate reference system

Each map item also has its own CRS setting under Main Properties (I1). By default, it is set to Use Project CRS. The map item then follows the CRS that is active in your QGIS project (see Coordinate system of the QGIS project). You can also choose a different CRS here, separately for each map item. This allows you to combine maps in different projections within a single layout. For example, you could use a national CRS such as Belgian Lambert 72 for a detail map and ETRS89-extended / LCC Europe for an overview map of Europe. Choosing a suitable projection for each map helps to minimise distortions at both scales.

Overview of another map

You might have noticed that the overview map in the example layout above shows a frame around the area that is covered by the detail map. QGIS can draw this frame automatically, so that it always matches the extent of the detail map exactly. Changing the scale of the detail map or moving its content updates the frame accordingly.

Try it yourself: Overview map and extent frame

You can easily add an overview through the Item Properties of the overview map:

  1. Go to the Overviews section (I5) and click the green plus symbol.
  2. A new overview is created and appears in the list below the plus and minus buttons. You can select an overview in this list to configure its properties.
  3. Under Map frame, select the map whose extent you want to display (in this case, the detail map).
  4. Under Frame style, configure the appearance of the frame. By default, this is a semi-transparent pink fill. In the example above, it was changed to a dark outline without a fill.

A layout can contain more than two maps. You can therefore add several overviews to a single map. It then shows several frames, each of which can be configured independently.

In the example layout above, two dashed lines connect the overview frame to the detail map itself. QGIS does not draw these lines automatically. They were added manually as arrow items, to make the map easier to read.

Grids

The Item Properties of a map also allow you to add one or more fully customisable grids (Grids, I4). These can be, for example, longitude and latitude lines or a grid in metres for a projected CRS.
